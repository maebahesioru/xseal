# xseal — X の投稿を「封印」して投稿する拡張

ツイート・DM の本文を、キーワード検索では引っかからない文字列に変換して投稿する Chrome / Firefox 拡張です。
読む側は拡張が自動で復号します。鍵は使いません（**暗号ではなく難読化**です）。

**配布ページ**: https://maebahesioru.github.io/xseal/

```
平文:   日本産の魚介類は終わってます
封印後: xoƍƟʅઽ¡¡¡¡のxoƍƲഔˊ¡¡¡¡はxoŬɹÑË¡¡¡¡
```

## できること

| 場所 | 動作 |
|---|---|
| 投稿欄 | ツールバーに `🔒` が出る。押すと本文が封筒に置き換わる（`Alt+S` でも可） |
| 選択範囲 | 文を選択して押すと、**選んだ所だけ**封印。まわりはそのまま残る |
| タイムライン / DM | 封筒を検出して `🔓 復号` チップを出す。押すと元の文が下に出る（自動復号も可） |
| 複数の封筒 | 1つの投稿に封筒が複数あれば、まとめて復号して元の文に差し戻す |
| 設定ページ | 封印/復号ツール、自動復号・フローティングボタンの切替、診断 |

## できないこと（先に言っておく）

- **凍結を防ぐ保証はない。** これは「本文に語がそのまま入らない」ようにするだけで、
  キーワード一致による検索・一括通報の経路を空振りさせるだけです。
- スクショ通報、アカウント単位の執行、既存の投稿の削除、X の規約判断には無力です。
- 秘密には使えません。拡張を持っている人なら誰でも復号できます。
- X 側の DOM は頻繁に変わります。動かなくなったら Issue をください。

## インストール

ストアには出していません。手元に読み込む形になります。

### Chrome / Edge / Brave

1. [Releases](https://github.com/maebahesioru/xseal/releases) から `xseal-chrome.zip` を取って展開する
   （またはこのリポジトリを clone して `node build.mjs`）
2. `chrome://extensions` を開く
3. 右上の「デベロッパー モード」を ON
4. 「パッケージ化されていない拡張機能を読み込む」→ 展開した `chrome/` フォルダを選ぶ

### Firefox

1. `xseal-firefox.zip` を展開する（または `build.mjs`）
2. `about:debugging#/runtime/this-firefox` を開く
3. 「一時的なアドオンを読み込む」→ `firefox/manifest.json` を選ぶ

> Firefox は一時アドオンなので、ブラウザを終了すると消えます。常用するには
> `about:config` で `xpinstall.signatures.required` を無効化して署名なしの xpi を入れてください。

## 使い方

1. x.com で投稿欄をクリック → 右上の `🔒` を押す
2. 本文が `xo…` で始まる文字列に置き換わる（重みが 280 を超えたら警告が出る）
3. そのままポストする
4. 読む側は拡張が `🔓 復号` を出し、押すと元の文が表示される

`Alt+S` でも封印できます。封印済みの本文を選択して押すと、その封筒を平文に戻します。

## 仕組み

**鍵なし・決定的**な方式です（同じ文は常に同じ封筒になります）。

1. 本文を UTF-8 にして圧縮（無圧縮 / deflate / 日本語用 Huffman / 文脈つき算術符号から最小を選ぶ）
2. 1バイトのヘッダ（使った圧縮方式 + 詰め物の数）を付ける
3. 2048 種の文字（**すべて X の重みが 1**）に 11bit ずつ詰め直す
4. 先頭に `xo` を付ける

X は日本語 1 文字を重み 2 で数えますが、使っている 2048 種の文字はすべて重み 1 です。
そのため 280 重みの 1 ポストに **実測 406 字**まで入ります（同じ本文を素の base64 にすると 6.7 倍重い）。

| 形式 | マーク | 文字集合 | 中身 |
|---|---|---|---|
| `plain`（既定） | `xo` | base2048 | 鍵なし。圧縮 + 算術符号 |
| `deep` / `ultra` / `self` | `x3` / `x4` / `x5` | base1024 / base2048 | 鍵なし・別モデル |
| `max` | `x2` | base1024 | 鍵なし・Huffman |
| `std` / `tight` | `x1` | base64url / base85 | AES-256-GCM（鍵あり） |

復号側はマークを見て方式を自動判定します。`x1`（鍵あり）はこの拡張の対象外です。

## ビルド

```bash
node build.mjs
```

`core/` の .mjs を 1 本の classic script に連結し、`chrome/` `firefox/` `docs/` を吐きます。
依存パッケージはありません（Node 18+）。

## ファイル構成

```
core/            封印コア（圧縮・算術符号・文字変換・封筒フォーマット）
src/             content script / options / manifest / アイコン
chrome/ firefox/ ビルド済みの拡張（そのまま読み込める）
docs/            GitHub Pages で配信するサイト（コアを内蔵した単体 HTML）
test/harness.html  ローカル回帰テスト（41 項目）
site/            サイトのテンプレート
```

## テスト

```bash
python3 -m http.server 18941
# → http://127.0.0.1:18941/test/harness.html を開くと結果がタイトルに出る
```

実際の X の DOM を模した 3 種類の入力欄（ツールバーあり / ツールバー無し / 属性なし）で、
ボタン挿入・本文置換・封印・復号・部分封印・複数封筒・モーダル時の表示順などを検証します。
